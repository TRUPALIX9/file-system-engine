# File System Engine Brand Pack

This pack contains production-ready starter SVG assets for the File System Engine product identity.

## Included

### Logos
- `fse-app-icon-master.svg` — primary app icon
- `fse-app-icon-small.svg` — simplified icon for small sizes
- `fse-logo-horizontal.svg` — horizontal logo lockup
- `fse-logo-stacked.svg` — stacked logo lockup
- `fse-logo-mono-dark.svg` — monochrome dark version
- `fse-logo-mono-light.svg` — monochrome light version

### UI icons
- navigation icons
- file action icons
- analysis icons
- device icons

### Design direction
The visual system uses:
- dark slate base
- cool blue to teal accent
- folder + engine-grid motif
- rounded desktop-product geometry

## Suggested next step
Use these as the base set, then refine visual polish in Figma or Illustrator if you want store-grade final exports for macOS `.icns` and Windows `.ico` packaging.
